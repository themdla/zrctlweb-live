Chapter 17

Advanced settings.

The Advanced page holds every app preference. It is split into five categories along the top: UI, Monitoring, Playback, Camera and System. This chapter walks through each category in order and lists every control with its options and default.

CategoriesUI · Monitoring · Playback · Camera · System
PersistenceEvery setting is saved on the device and survives relaunches
VersionThe app version and build number are shown at the bottom of every category

Most of the UI and Monitoring settings are also captured in Live View presets, so you can keep several complete layouts and switch between them. The Presets section at the end lists exactly what a preset stores.

UI

Everything about how the app and the Live View page look. Cards in order: Language, Navigation, Live View Layout, Hot Corners (Modern interface only), Top Toolbar, Bottom Toolbar.

Language

Where

Default
System Default, which follows the iPhone's language

Changes every string in the app immediately. Arabic and Urdu also flip the general interface to right-to-left; the Live View HUD, playback transport, scopes and keypads stay left-to-right because camera surfaces read that way everywhere. Support logs always stay in English so they can be read by support.

When to change it

Only if you want a language other than your phone's. The translations are reviewed but still young; if a label reads oddly, send feedback with the wording.

The page the app jumps to when a connection completes while you are on the Connection page. If you have already moved to another page, nothing moves.

Live View Layout card

Interface

Options
Modern, Classic
Default
Classic

Modern is the layout with hot corners: up to two tools in each landscape corner, around the picture. Classic is the original toolbar layout. Choosing Modern reveals the Hot Corners card; choosing Classic reveals the Raise Bottom Toolbar tile. This choice is not stored in presets.

When to change it

Modern suits one-handed landscape use on a cage, with your most used tools under your thumbs. Classic keeps everything in the toolbars and is easier to learn.

Top Toolbar card

Top Toolbar Scale

Range
70% to 160% in 5% steps
Default
100%

Scales the readout chips in the top bar. Larger chips take more width, which the fit meter below reports.

Arrangement (hold and drag to reorder)

Default order
Mode, Aperture, Shutter, ISO, Exposure Compensation, GAP, Dual Base ISO, WB, Kelvin, WB Tint, Battery

A strip of sample chips you can reorder by long-pressing and dragging. The dashed GAP splits the bar into the landscape left group and right group. Below the strip a fit meter shows how much of the landscape width each group uses. On iPhone a group that no longer fits shows a red warning that the bar will scroll, and the advice is to remove a readout, move one across the gap, or lower the scale. Battery chips do not count toward the width because they sit in the side gutters in landscape.

Monitoring

How the picture is analysed and displayed. Cards in order: Scopes, Preview, LUT Library, Focus Peaking.

Scopes card

Analyze Pre-LUT

Options
On / off
Default
On

Scopes, zebras and false color read the camera signal before the LUT is applied, so they measure what is being recorded rather than what the look shows. Turning it off makes them read the LUT output instead.

When to change it

Leave it on for log and RAW. Turn it off only when you are deliberately recording a baked-in Rec.709 look and want the scopes to show the final image, or when a colourist asks for a scope of the graded picture.

False Color Legend

Options

Default
On

Shows the colour key while false color is active. The legend can be dragged in Live View.

Default
X-Zone

Selects the palette the False Color tool paints with. The same choice is available from the FALSE pill's long-press menu in Live View; the palettes are described in Exposure tools.

135%

Preview card

These settings control the Live View stream the camera sends to the phone. They do not affect what the camera records.

Preview resolution

Options
QVGA 320x240, VGA 640x480, XGA 1024x768
Default
Seeded on first connection by transport: VGA for Wi-Fi and camera AP, XGA for USB

The size of the JPEG frames the camera sends. With a camera connected the value is written immediately; otherwise it is saved and applied when Live View starts. Changing the preview size from the Live View or Controls pickers updates this saved value too.

When to change it

Drop to VGA or QVGA when Wi-Fi Live View stutters or lags; the picture gets softer but the frame rate and responsiveness recover. XGA is right for USB and for a strong 5 GHz router.

Preview quality

Options
Basic, Basic+, Normal, Normal+, Fine, Fine+
Default
Seeded on first connection: Normal+ for Wi-Fi and camera AP, Fine+ for USB

The JPEG compression of each preview frame. Higher quality means more detail and a heavier stream. Some older bodies do not accept this write and keep their own value.

When to change it

Pair it with resolution: lower both together on a weak link, raise both on USB. Fine+ over a crowded Wi-Fi network is the most common cause of a choppy preview.

Fast GPU Display

Options
On / off
Default
On

Draws the monitor picture directly on the GPU (a Metal surface) for the lowest latency. Off falls back to a standard image view. Called "Metal Monitor Surface" in 2.0.

When to change it

Only turn it off if the monitor picture glitches, tears or shows the wrong aspect, which is rare. Not stored in presets.

USB Preview Rate New in 2.1

Options
Standard (up to 60 fps), Maximum (matches the screen, up to 120 fps on ProMotion displays)
Default
Standard

Caps how many Live View frames per second the app asks for over USB. Maximum is smoother on a 120 Hz iPhone or iPad but loads the camera's USB link more. It applies the next time USB Live View starts, and recording is never affected.

Adaptive Wi-Fi Heartbeat New in 2.1

Options
On / off
Default
On

On router Wi-Fi, spaces the camera status checks between Live View frames instead of running them on a fixed timer, which keeps the preview smoother on a busy network. USB and camera AP connections keep a fixed heartbeat.

When to change it

Turn it off if Wi-Fi Live View drops or stutters after an update and you want to rule this out. Send logs either way.

LUT Library card

Import .cube LUT… and the imported list

Lists the LUTs you have imported, with the places each is used. Import .cube LUT… opens the Files picker filtered to .cube files and copies the LUT into the app. The row of the LUT currently active in Live View is highlighted. Bundled LUTs are not listed here; they live in the LOOK browser in Live View.

Delete on a row asks for confirmation and lists which settings reference the LUT. After deleting, every place that used it (the Live View LUT, quick slots, playback LUT B, presets) switches back to the default LUT. Nothing here is written to the camera.

When to use it

Import the show LUT or your colourist's conversion LUT before the shoot. If a LUT fails to import, the file is usually not a 3D .cube or is corrupt; re-export it from your grading software.

Focus Peaking card

Sensitivity

Range
0% to 100%, continuous slider
Default
85% (the old Low, Medium and High steps map to 12%, 46% and 85%)

How fine an edge must be to receive a peaking mark. Peaking judges sharpness relative to the surrounding scene, so a given value behaves the same in SDR, log and low light. Higher values mark finer detail; very high values start to pick up sensor grain.

When to change it

Lower it on noisy, high-ISO scenes where grain gets marked. Raise it for flat, low-detail subjects like faces in soft light that otherwise show few marks.

Mono Background

Options
On / off
Default
Off

While peaking is on, the picture goes monochrome so the coloured peaking ridges are the only colour on screen.

When to use it

Use it when the subject's own colour matches the peaking colour, or whenever you are pulling focus by eye and do not need colour for anything else.

Color

Options
Red, Yellow, Green, White, Cyan
Default
Red

The colour of the peaking ridges. Pick one that contrasts with the scene: cyan or white on warm interiors, red or yellow on blue skies and greenery.

Playback

Cards in order: Playback LUT, Playback.

Start playback on

Options
LUT A · Live View, LUT B · Saved
Default
LUT A · Live View

Which LUT slot the clip player starts with. LUT A follows whatever LUT Live View is using. LUT B is a saved playback look, chosen below. The A/B button in the player switches between them.

LUT B

Options
Every bundled and imported LUT
Default
The bundled N-Log to Rec.709 conversion

The LUT used by playback slot B. If the chosen LUT is later deleted, the slot falls back to the N-Log conversion.

When to change it

Set LUT B to a plain technical conversion for the footage you shoot (N-Log to Rec.709, or an IPP2 LUT for R3D) so you can always compare the creative look in slot A with a neutral one.

Card read speed and Test Link Speed

The readout shows the transport and the measured throughput of recent card reads, with the link class and the session peak. Test Link Speed reads a short sample from the newest large file on the card and reports the link class, the rate, the sampled size and the file name. It needs a connected camera with files on the card.

When to use it

Run it when playback is slow to tell a slow link from a slow card. USB 3 reads several times faster than USB 2, and both beat Wi-Fi; if a USB-C cable reports a USB 2 class, try a different cable.

Clip cache limit

Options
20 GB, 30 GB, 40 GB, 50 GB
Default
40 GB

The maximum size of the local playback cache, which keeps streamed clip ranges and downloaded clips so recently opened clips start faster. Choosing a smaller value prunes the cache immediately and reports the size removed.

Clear Playback Cache

Deletes all cached clip data and reports how much was freed. The caption shows the current cache size. Use it when the phone is short on storage; nothing on the camera card is touched.

Camera

Cards in order: Startup Defaults, Slow Motion Target, Lens Profiles.

The six target rows in the first two cards share one behaviour. Each shows the saved value or Not Set. With a camera connected that exposes the property, tapping the row opens a menu with Use Current (copies the camera's value), every value the camera allows, and Clear Target. Choosing a value saves it; nothing is written to the camera at that moment.

Startup Defaults card

Slow Motion Target card

RowOptionsWhat it does
Target Res / FPSThe camera's allowed frame sizes and ratesThe format the SLOW tool in Live View switches the camera to. Turning SLOW on remembers the current format and writes this one; turning it off restores the remembered format.
Target CodecThe camera's allowed codecsThe codec written together with the target format.
When to use it

Save your high-frame-rate format here once, for example 1080p 120 fps H.265, and the SLOW pill becomes a one-tap slow-motion switch. The slow-motion state resets every launch so you never start a day stuck in 120 fps.

Lens Profiles card

Profile list

Each saved manual-lens profile shows its name, focal length, maximum aperture, the camera slot number when known, and a note when the camera's slot holds different values. Write sends the focal length and aperture into the camera's Non-CPU Lens Data so in-body stabilisation and metadata are correct. The … menu offers Rename and Delete. Write appears only with a connected camera that reports writable non-CPU lens data.

Add Lens Profile

Fields
Focal (mm), Aperture, Name (optional)

Pick a focal length and maximum aperture from the values Nikon bodies accept, optionally name the profile, and tap Add Profile. A blank name becomes a suggested name built from the values. Profiles can also be created from the LENS tool in Live View, which is also where you import the lenses already stored in the camera. See Focus tools.

System

App

Read-only rows for Version, Build, Source (the short commit the build was made from) and Device (model and iOS version). Include the version and build in any support email; the same string is repeated in the page footer.

Automatic Diagnostic Upload

Options
On / off
Default
Off

After a connection or Live View failure, uploads the support log automatically so the problem can be investigated without a Send Logs email. No camera footage is included. The same switch is offered from the Connection page's support views.

When to use it

Turn it on if you are working with support on a recurring problem, so each failure is captured even when you are busy shooting.

Developer Mode

A passcode-protected switch that reveals diagnostic and calibration tools used during development and support. It is not needed for normal use, and its contents are not covered by this manual. Support may ask you to enable a specific tool during troubleshooting.

Presets

Presets are saved and recalled from the Presets (SAVE) tool in Live View, but most of the UI and Monitoring settings above are part of them. On first launch three presets are created from the defaults and then behave like any other preset: you can rename, overwrite or delete them.

PresetWhat it sets
Full HUDEvery bottom-toolbar tool and stills readout on, default top bar, labels shown, hot corners at their defaults.
CleanSame as Full HUD with Icons Only and Hide Labels on.
MinimalLabels hidden; bottom toolbar reduced to HUD Toggle, Record Controls, LUT Toggle, Scopes, Image Tools, False Color and Audio; top bar reduced to Aperture, Shutter, ISO on the left and WB, Battery on the right.

What a preset stores

  • Optionally the recording format (frame size, rate and codec) and the slow-motion state. Built-in presets do not store a format; a preset that carries one writes it to the camera when recalled.
  • Preview resolution and quality (user presets only).
  • Overlay visibility, FPS counter, recording border, recording timer, remaining time, HUD style, Tool Toggle or Tool Menu, Tools Stay On, Raise Bottom Toolbar, rotation lock, portrait fill, landscape toolbar side.
  • LUT on/off, the selected LUT, LUT Match values, Analyze Pre-LUT.
  • Scope mode, exposure assist mode, zebra and image-tool mode, false color legend and style, scope size and opacity.
  • Composition guide, frame guide, frame guide scale, matte opacity, guide opacity, desqueeze.
  • Focus peaking on/off, sensitivity, colour, mono background.
  • Level, audio meters and exposure meter on/off, level readout.
  • Bottom-toolbar tool and stills-readout visibility; top-bar chip visibility and order; Icons Only; Hide Labels; every scale; floating tool positions; hot corner enable, sides and all slot assignments.

Not stored: Language, Open After Connecting, Interface (Modern or Classic), Touch AF Hides Box, Fast GPU Display, USB Preview Rate, Adaptive Wi-Fi Heartbeat, the playback settings, startup defaults, slow-motion targets, lens profiles, support upload and Developer Mode.

Reset actions

There is no single "reset everything" button. The resets that exist are Reset On-Screen Tool Positions (UI), Clear Target on each startup or slow-motion row (Camera), Clear Playback Cache (Playback), and deleting an imported LUT (Monitoring). To return the Live View layout to a known state, recall the Full HUD preset.

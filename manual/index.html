      User manual

      Everything in the app, explained.

      This manual covers every page, tool and setting in Parallax Monitor for iPhone, iPad and Android (the Android app was formerly ZR Ctl). It also explains the cinematography behind each tool, so you know not just what a setting does but when to reach for it.

      Written forParallax Monitor 2.1 (iOS and Android)
      CamerasNikon Z series and RED KOMODO / V-RAPTOR
      Quick setupSee the How-to page for cable and Wi-Fi setup

      How to use this manual

      Start with Tips and tricks for the habits that save the most time, and check Known issues before a shoot. If you are new to video, read Cinematography basics. It explains exposure, log footage, LUTs, scopes and focus in plain language and points to the tool in the app that handles each one. Everyone else can jump straight to the chapter for the page they are on. Each chapter lists every control on that page with the same structure: what it is called on screen, where it lives, the options it offers, what it does, and when to use it.

      Use the search box in the sidebar to find a tool by its on-screen name, for example ZEBRA, MATCH or Rec TC. The glossary at the end defines every term the app and this manual use.

      The pages of the app

      The app has seven destinations, reached from the page switcher. Each has its own chapter.

      The one rule for every tool

      Every tool pill in Live View works the same way. Tap turns the tool on or off. Long-press opens its options. That is true for scopes, zebras, false color, peaking, LUTs, guides, desqueeze, the level, audio meters and the rest. If you remember nothing else from this manual, remember that.

      Tip

      If you prefer a tap to open the options menu instead of toggling, you can change that per tool in Advanced, under the bottom toolbar settings. See Advanced settings.

      Which version this describes

      This manual is written against Parallax Monitor 2.1 for iOS, which is the baseline for both apps. Features that arrived in 2.1 are marked New in 2.1. If you are on 2.0 and cannot find one of those, update the app.

      Parallax Monitor for Android shares the same tools, names and layout. Where Android behaves differently, the chapter says so in an Android note. Features that exist only on one platform are marked with iPad, iOS or Android.

      Feature availability also depends on the camera. A control that the camera does not report is hidden or shown as read only, so two bodies can present slightly different Controls grids. The Supported cameras chapter lists the differences.

      Getting help

      If something does not work, the most useful thing you can do is send logs right after it fails. Open the Connection page and tap Send logs. The email contains a filtered support report from the app, with no photos or video. Add one or two sentences about what you expected and what happened. Feature requests and bug reports can also go through the feedback form.

      Setup walk-throughs with camera menu screenshots are on the How-to page, and the video tutorials show the tools in use.

      Something missing or wrong on this page? Email mike@itsmadcreative.com with the page name and what you expected to find.
